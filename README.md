# Sea_Battle_Game
Console game "Sea Battle" implemented in C++ for university practice. 

### Game overview:
The idea of this project is to create a simple console Sea Battle game in C++.
  A player will play against the computer on a standard 10x10 grid.

### Features for MVP:
###### -> Show two 10x10 fields with coordinates (A-J, 1-10) in the console.
###### -> Random and automatic ship placement at the start of the game.
###### -> Player enters coordinates, game checks for hit or miss and bot makes a random blast.
###### -> Use symbols(X, ~, #) to represent elements of game.
###### -> Add a menu for starting a new game and exiting.
###### -> Game ends automatically when all ships of one player are destroyed.
###### -> Display messages for hits, misses, and game over.

### Future improvements:
###### -> Add different types of ships with varying sizes.
###### -> User can choose ship placement or use random placement.
###### -> Add colorful console output and sounds for better user experience.

### Tech Stack
###### -> Visual Studio for development and debugging.
###### -> C++ for game logic and console output.
###### -> Standard libraries for input/output and random number generation.
###### -> Modular design with classes
